
# Cisco Catalyst Center - Access Point Monitoring

## Overview

This repository covers wireless access point monitoring using Cisco Catalyst Center.

I use Catalyst Center to check access point status and investigate wireless connectivity issues.

## Access Point Monitoring

My main tasks include:

- Checking whether access points are online or offline
- Reviewing access point health and status
- Checking device details and connectivity
- Reviewing alerts when an access point has an issue
- Identifying access points that need further troubleshooting

## Basic Troubleshooting

When an access point is showing offline or has a connectivity issue, I start by checking:

1. Access point status in Catalyst Center
2. Available alerts and device information
3. Network connectivity
4. Connected switch port status
5. Whether the issue needs further investigation
